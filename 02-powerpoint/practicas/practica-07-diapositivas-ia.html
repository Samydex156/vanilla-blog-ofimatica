Práctica #07

Generación de Diapositivas con Inteligencia Artificial (pptxgenjs)

Uso de una skill de IA para generar presentaciones .pptx programáticamente con Node.js y pptxgenjs

Objetivo de la Práctica

El estudiante descargará la skill skill-pptxgenjs-decks-portable.md, comprenderá cómo un agente de IA puede generar presentaciones PowerPoint de forma programática con Node.js y la librería pptxgenjs, y producirá una presentación completa sobre un tema asignado sin errores de reparación de PowerPoint.

Material de Trabajo

Descarga el documento de la skill que contiene las instrucciones técnicas para la generación de presentaciones:

🤖 Descargar Skill: pptxgenjs-decks (.md)

Instrucciones Paso a Paso

1. Descarga y Estudio de la Skill

  • Haz clic en el botón superior para descargar el archivo skill-pptxgenjs-decks-portable.md.
  • Lee el documento y anota los conceptos clave: layout LAYOUT_WIDE (13.33 x 7.5 in), formas válidas (rect, roundRect, ellipse, line), tipos de gráfico permitidos (bar, doughnut, line, pie) y el post-proceso de charset.

2. Preparación del Entorno

  • Instala Node.js si no lo tienes (la skill documenta que es un proyecto Vanilla, pero esta práctica usa Node.js de forma puntual para la generación de archivos).
  • Crea una carpeta de trabajo, inicializa el proyecto e instala las dependencias:
npm init -y npm install pptxgenjs jszip pdf-parse

3. Generación de la Presentación con un Agente de IA

  • Abre tu herramienta de IA (Command Code, Gemini CLI, Claude, etc.) y activa la skill pptxgenjs-decks.
  • Solicita la generación de una presentación con un tema definido, indicando el número de diapositivas, por ejemplo:
/pptxgenjs-decks Energías renovables en el Perú 8
  • Revisa que el generador use el layout LAYOUT_WIDE, formas válidas y guarde con el post-proceso de charset.
  • Pide al agente que verifique el archivo generado antes de entregarlo (salida esperada: OK: sin valores inválidos).

4. Verificación y Apertura en PowerPoint

  • Abre el archivo .pptx generado en Microsoft PowerPoint y confirma que no aparezca la alerta de reparación.
  • Compara el resultado con una presentación creada manualmente e identifica ventajas y limitaciones de la generación automática.
Consejo: El documento de la skill incluye un cheat sheet con los valores correctos y problemáticos (layout, formas, chart, charset). Consúltalo para depurar rápidamente cualquier presentación generada.
Entregable

Guarda el archivo final con el nombre P07-DiapositivasIA-TuNombre.pptx y preséntalo junto con un breve resumen del prompt utilizado y el proceso seguido.
