  • Cavalry — Diseño Animado 2D

    Animación / Motion

    Software profesional de animación 2D procedural en tiempo real, gratuito para particulares vía cuenta Canva. Alternativa liviana a After Effects para motion con shapes, texto, duplicator, rigs y exportación Lottie/MP4. Ideal para introducir animación sin licencias. cavalry.studio

    Principios básicos (mini-teoría)
    • Procedural: una sola modificación propaga sistemas completos (rigs, duplicadores, falloffs).
    • Tiempo real: viewport GPU acelerado, sin espera de preview.
    • Datos en movimiento: vincula CSV/hoja de cálculo y genera animaciones a escala.
    • Export: Lottie, secuencia PNG, MP4 — listo para web/redes.
    Requisitos y compatibilidad (PCs del instituto)
    • Oficial: Windows 10+, 512 MB RAM mínimo, GPU OpenGL 4.1, Intel Gen 12 Alder Lake o superior, internet para login Canva (docs/requirements).
    • Real en i3 4GB integrada: suficiente para fundamentos (shapes, texto, duplicator, <15 capas en 1080p). Proyectos complejos pueden dar viewport blanco o lag si la iGPU no soporta OpenGL 4.1 — actualizar driver Intel y probar Help > System Diagnostics antes del curso.
    • Cuenta: gratuita con Canva (no hay versión de pago desde v2.7). Si falla, plan B: Synfig / Blender Grease Pencil.
