Guía 01

Cómo Crear tu Primera Tabla en Access

Vista Diseño — tipos de datos — clave principal

Objetivo

Al finalizar podrás crear la tabla Clientes con campos bien tipados y clave principal autonumérica lista para relacionar.

Pasos

1. Crear la base

Access → Base de datos en blanco → nombre PracticaAccess_TuNombre.accdb → Crear. Se genera Tabla1; ciérrala sin guardar para empezar en Vista Diseño.

2. Ir a Vista Diseño

Pestaña Crear → Tabla → botón Vista → Vista Diseño. Nombra la tabla Clientes.

3. Definir campos

CampoTipo de datosDescripción
IdClienteAutonumeraciónClave principal
NombreCompletoTexto corto (80)Requerido = Sí
CiudadTexto corto (40)Valor predeterminado: La Paz
TelefonoTexto corto (15)Máscara de entrada opcional
FechaRegistroFecha/HoraPredeterminado = Ahora()
ActivoSí/NoCasilla de verificación

4. Clave principal

Selecciona IdCliente → clic derecho → Clave principal (icono llave). Access no permitirá duplicados ni nulos en ese campo.

5. Guardar y probar

Guarda (Ctrl+G), cambia a Vista Hoja de datos e ingresa 3 registros de prueba. Observa cómo IdCliente se autonumera.

Consejo

Usa Texto corto para códigos/teléfonos (no números) y Número solo para cálculos. Define Tamaño del campo abajo para optimizar almacenamiento.
