Introducción a Microsoft Access

Qué es una base de datos — Entorno de trabajo — Objetos de Access

Resumen de la Clase

En esta primera clase del módulo de Microsoft Access conocerás el propósito de un sistema gestor de bases de datos relacional (SGBD) y cómo Access te permite almacenar, relacionar y consultar grandes volúmenes de información sin depender de planillas dispersas.

1. ¿Qué es Microsoft Access?

Es el gestor de bases de datos de Microsoft Office. Permite crear tablas relacionadas, formularios para carga de datos, consultas para filtrar información e informes para impresión. A diferencia de Excel, Access impone estructura y tipos de datos, garantizando integridad referencial.

Usos principales:
  • Gestión de clientes, inventario y facturación.
  • Control de préstamos, biblioteca y asistencia.
  • Generación de consultas y reportes automatizados.
  • Creación de formularios para captura de datos sin errores.
  • Integración con Word (correspondencia) y Excel (importación).

2. Ventana Principal de Access

Access organiza el trabajo en objetos visibles en el panel de navegación izquierdo y el área central:

Objetos de Access

  1. Tablas: Almacenan los datos estructurados en filas y columnas con tipos definidos.
  2. Consultas: Filtran y combinan datos de varias tablas (ej. clientes de La Paz).
  3. Formularios: Interfaces visuales para ingresar/editar registros sin tocar la tabla.
  4. Informes: Salidas imprimibles con agrupaciones y totales.
  5. Relaciones: Reglas de integridad entre tablas (clave primaria/foránea).
Dato clave

Un archivo Access se guarda como .accdb y contiene todos los objetos en un solo contenedor. Colócalo en practicas/ejercicios/ para descarga directa.
