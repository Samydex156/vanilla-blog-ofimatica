Guía 05 — Photopea

Photopea: Capas, Texto y Exportación Profesional

De una foto plana a un montaje con capas y exportación perfecta para Word/PowerPoint

Objetivo

Dominar capas, añadir texto y formas, aplicar un filtro y exportar en el formato correcto (JPG, PNG transparente o PSD editable).

Paso a Paso

  1. Duplicar capa base: En panel Capas, clic derecho sobre “Fondo” → Duplicar capa. Trabaja siempre sobre copia para no perder el original (candado).
  2. Añadir texto: Herramienta T (Texto) → clic en el lienzo → escribe “Instituto Nueva Tecnología”. En la barra superior cambia fuente a Inter / Arial Bold, tamaño 48px, color blanco. Añade sombra: clic derecho en capa de texto → Opciones de fusión → Sombra paralela (opacidad 40%).
  3. Forma y color: Herramienta Rectángulo (U) → dibuja un rectángulo detrás del texto → en Propiedades elige relleno #03A9F4 (azul internet) y opacidad 85%. Arrástralo debajo de la capa de texto en el panel.
  4. Máscara rápida (quitar fondo simple): Selecciona capa de imagen → herramienta Varita mágica (W) → clic en fondo blanco → Supr para borrar. Si queda borde, usa Seleccionar → Perfeccionar borde.
  5. Filtro sutil: Selecciona la capa de foto → Filtro → Desenfoque → Desenfoque gaussiano 2px solo para el fondo (si usaste máscara, el sujeto queda nítido). O prueba Filtro → Enfocar → Máscara de enfoque para resaltar.
  6. Orden y opacidad: Reordena capas arrastrando; baja opacidad de la forma a 70% para que la foto se asome. Usa Ctrl+T (transformación libre) para escalar/mover con Shift para proporción.
  7. Guardar editable: Archivo → Guardar como PSD → se descarga montaje.psd con capas intactas (por si debes corregir en clase).
  8. Exportar final:
    • Para Word/PowerPoint (fondo blanco): Archivo → Exportar como → JPG → calidad 90% → Guardar.
    • Para logo/sticker (fondo transparente): oculta capa “Fondo” (ojo) → Exportar como → PNG → marca Transparencia.
    • Para web: Exportar como → PDF si el docente pide vector.

Atajo clave de capas
  • Ctrl+J duplica capa, Ctrl+T transforma, Ctrl+G agrupa.
  • Ojo = mostrar/ocultar, candado = bloquear. Arrastra para reordenar.
  • Si te equivocas: Historial a la derecha → clic en estado anterior.

Checklist antes de exportar

  • ¿Texto legible? (contraste con fondo, sombra si hace falta)
  • ¿Bordes limpios? (zoom 100% para revisar)
  • ¿Tamaño final 1920 px ancho máximo (ofimática)?
  • ¿Guardaste PSD + JPG/PNG?
