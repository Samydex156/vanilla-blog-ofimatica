Guía 04 — Photopea

Photopea Básico: Abrir, Interfaz y Primeros Ajustes

De pixabay.com a tu primera edición sin instalar nada

Objetivo

Abrir Photopea, reconocer su interfaz y hacer tu primera edición: recorte + brillo/contraste + redimensionado.

Paso a Paso

  1. Abrir Photopea: En Edge/Chrome ve a www.photopea.com. Espera que cargue (barra azul). Si hay anuncio lateral, ciérralo con la X. Tip 4GB: cierra otras pestañas.
  2. Abrir imagen: Descarga antes una foto de Pixabay (ej. “oficina”). En Photopea: Archivo → Abrir o arrastra el JPG al lienzo. Verás la imagen en el centro y una capa a la derecha.
  3. Reconocer la interfaz (5 zonas):
    • Menú superior: Archivo, Editar, Imagen, Capa, Filtro.
    • Herramientas (izquierda): Recortar (C), Mover (V), Pincel (B), Texto (T), Zoom (Z).
    • Lienzo (centro): tu foto con guías y zoom (Ctrl + ruedita).
    • Capas (derecha): cada elemento es una capa; el candado indica fondo bloqueado.
    • Historial / Propiedades: deshace con Ctrl+Z paso a paso.
  4. Recortar: Selecciona herramienta Recortar (C) → arrastra un rectángulo → presiona Enter. Para práctica: deja proporción 16:9 (ideal para PowerPoint).
  5. Ajuste básico: Imagen → Ajustes → Brillo/Contraste → sube Brillo +10, Contraste +15 → Aceptar. Prueba también Imagen → Ajustes → Intensidad (saturación).
  6. Redimensionar: Imagen → Tamaño de imagen → ancho 1920 px (alto se ajusta solo) → Aceptar. Es suficiente para ofimática y no satura 4GB.
  7. Guardar rápido: Archivo → Exportar como → JPG → calidad 85% → Guardar. Se descarga a Descargas. Renómbrala foto-editada-01.jpg.

Error común en el aula

“No veo la imagen después de abrir” → revisa el zoom (Ctrl+0 ajusta a pantalla) o la capa está oculta (ojo tachado en panel Capas → clic para mostrar).
