Práctica 05 — Photopea

Montaje con Capas: Texto + Imagen + Exportación

Crea una portada para PowerPoint combinando 2 fotos de Pixabay, texto y forma

Objetivo

Combinar 2 imágenes en capas, añadir texto con sombra y forma de color, y exportar en JPG (fondo blanco) y PNG transparente + PSD editable.

Material

  • Foto A (fondo): paisaje o oficina de Pixabay, horizontal.
  • Foto B (sujeto): objeto/persona con fondo claro para recorte fácil.

Instrucciones

  1. Lienzo base: Photopea → Archivo → Nuevo → 1920×1080 px, 72 dpi, fondo blanco → Crear.
  2. Traer Foto A: Archivo → Abrir y colocar → foto A → Enter para confirmar. Cubre el lienzo con Ctrl+T si hace falta.
  3. Traer Foto B: Archivo → Abrir y colocar → foto B → con Ctrl+T redúcela a 1/3 del lienzo y colócala abajo a la derecha.
  4. Quitar fondo de Foto B (si es necesario): Selecciona su capa → W (Varita) → clic en fondo blanco → Supr. Si el borde queda duro, Seleccionar → Perfeccionar borde 1px.
  5. Texto: T → escribe “Aprende Ofimática” arriba al centro → fuente Inter Bold 72px, blanco → capa texto → Opciones de fusión → Sombra paralela opacidad 35%, distancia 4px.
  6. Forma detrás del texto: U (Rectángulo) → dibuja rectángulo detrás del texto → relleno #03A9F4, opacidad 80% → arrastra la capa debajo del texto.
  7. Ajuste final: Selecciona capa Foto A → Filtro → Desenfoque gaussiano 2px para que el texto resalte (opcional).
  8. Guardar editable: Archivo → Guardar como PSD → montaje-capas.psd (conserva capas).
  9. Exportar JPG: Ojo de fondo activado → Exportar como → JPG 90% → portada-powerpoint.jpg.
  10. Exportar PNG transparente (extra): Oculta capa Fondo (clic en ojo) → Exportar como → PNG con transparencia → logo-recorte.png.
Criterio de evaluación
  • Capas ordenadas (fondo → foto B → forma → texto arriba).
  • Texto legible con contraste/sombra.
  • Bordes limpios en el recorte (zoom 100%).
  • Tres archivos: montaje-capas.psd, portada-powerpoint.jpg, logo-recorte.png (opcional).
Entregable

Entrega portada-powerpoint.jpg insertándola como portada en PowerPoint Práctica 01. Si el docente lo pide, adjunta también el .psd para revisar capas.

Tip uBlock + Photopea

Con uBlock Origin activo, Photopea no muestra anuncios laterales que tapan el lienzo en 1366×768. Combina ambas clases para un flujo limpio.
