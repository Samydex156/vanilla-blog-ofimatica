Práctica 08 — Guiada

Generar una Carta Formal con OpenCode y Word

De la idea al .docx listo para imprimir — prompt → plan → generación → formato en Word

Objetivo

Usar OpenCode (CLI o Desktop) para generar el contenido de una carta formal modelo, exportarlo a .md/.docx y darle formato profesional en Word según el módulo 01 (márgenes, estilos, sangrías, firma).

Pre-requisitos

  • OpenCode instalado (Guía Windows) y proveedor conectado (/connect).
  • Word instalado. Repasa Anatomía del documento formal y Fuente y tamaño.

Paso 1 — Abrir el proyecto y pedir el plan (Tab)

cd C:\dev\vanilla\vanilla-blog-ofimatica
opencode

Presiona Tab para entrar a Plan (verás “Plan mode” abajo a la derecha) y pega este prompt guiado:

Actúa como asistente administrativo del Instituto Nueva Tecnología. Necesito una carta formal en español, en formato A4, de una página, con tono respetuoso y claro.

Contexto: solicitud de constancia de estudios para presentar a una empresa. Destinatario: Jefe de Recursos Humanos. Remitente: estudiante de Ofimática (deja placeholders [NOMBRE], [CARNET], [FECHA], [EMPRESA]).

Estructura obligatoria: membrete, lugar y fecha, destinatario, asunto (Asunto: Solicitud de constancia de estudios), saludo, 3 párrafos (presentación + motivo + compromiso/agradecimiento), despedida, firma con cargo, pie con contacto. Usa lenguaje formal boliviano.

Propón primero el plan: qué archivos crearás y qué validaciones harás, sin generar aún el documento.

Revisa el plan que propone OpenCode. Si te gusta, presiona Tab de nuevo para pasar a Build.

Paso 2 — Generar el borrador con OpenCode

En Build, confirma:

Perfecto, genera ahora el archivo 06-inteligencia-artificial/practicas/archivos/carta-constancia-borrador.md con la carta completa y placeholders visibles.

Abre el .md generado. Verifica con el docente que tenga los 7 elementos de una carta formal (membrete, fecha, destinatario, asunto, cuerpo, despedida, firma).

Variación del prompt (para practicar)

Cambia el motivo a “solicitud de práctica pre-profesional” o “carta de recomendación”. Observa cómo el mismo prompt estructurado (rol + tarea + formato + tono) genera resultados distintos sin reescribir todo.

Paso 3 — Pasar a Word y aplicar formato profesional

  1. Copia el contenido del .md a un nuevo Word (Carta_Constancia_TuNombre.docx).
  2. Aplica del módulo Word: fuente Calibri 11 o Arial 12, interlineado 1.15, alineación justificada en cuerpo, sangría primera línea 1.27 cm, márgenes 2.54 cm.
  3. Encabezado con logo/membrete “Instituto Nueva Tecnología — Ofimática”, pie con teléfono y correo (usa Insertar → Encabezado/Pie).
  4. Reemplaza placeholders [NOMBRE], [FECHA] con tus datos y guarda.
  5. Exporta a PDF con Archivo → Exportar → Crear PDF para verificar vista de impresión (usa Ctrl+P del portal como referencia).

Paso 4 — Verificar con OpenCode (opcional pero recomendado)

Revisa @06-inteligencia-artificial/practicas/archivos/carta-constancia-borrador.md y dime si cumple con: asunto explícito, 3 párrafos, tono formal y placeholders. Sugiere 2 mejoras sin reescribir todo.

Usa /undo si alguna edición no te convence y /share para generar el link de entrega.

Entregable
  1. carta-constancia-borrador.md generado por OpenCode (en 06-inteligencia-artificial/practicas/archivos/ o captura del chat).
  2. Carta_Constancia_TuNombre.docx y .pdf con formato Word aplicado.
  3. Link /share de la conversación Plan → Build.

Tip Desktop: mismos pasos en OpenCode Desktop → Open Project → terminal integrada → opencode.
