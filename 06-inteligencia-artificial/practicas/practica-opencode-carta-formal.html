Generar una Carta Formal con OpenCode y Word

Tamaño carta — carpeta Escritorio\documentos-ia — generación con Node.js + docx

Objetivo

Usar OpenCode (CLI o Desktop) para generar una carta formal tamaño carta con Node.js + npm + dependencia docx, guardada en Escritorio\documentos-ia\, y validarla en Word.

Ubicación de trabajo obligatoria

Todas las prácticas de IA se guardan en el Escritorio para evitar rutas largas y facilitar la entrega. Crea la carpeta una sola vez:

mkdir "%USERPROFILE%\Desktop\documentos-ia"
mkdir "%USERPROFILE%\Desktop\documentos-ia\carta-constancia"

Equivale a C:\Users\TuUsuario\Desktop\documentos-ia\. Si ya existe, omite el primer mkdir.

Pre-requisitos

  • OpenCode instalado (Guía Windows) + Node.js LTS verificado con node --version y npm --version.
  • Word para verificar el .docx final (impresión tamaño carta).

Paso 1 — Abrir OpenCode y pedir el plan (Tab)

cd "%USERPROFILE%\Desktop\documentos-ia\carta-constancia"
opencode

Presiona Tab para entrar a Plan y pega este prompt (usa el botón Copiar para evitar errores):

Actúa como asistente administrativo del Instituto Nueva Tecnología.

TAREA: Genera una carta formal en español, TAMAÑO CARTA (Letter 8.5" x 11" = 21.59 x 27.94 cm), de una página, tono respetuoso y claro, usando Node.js y npm con la dependencia docx (npm install docx). El script debe crear el .docx programáticamente, no copiar texto manual.

CONTEXTO: Solicitud de constancia de estudios para presentar a una empresa. Destinatario: Jefe de Recursos Humanos. Remitente: estudiante de Ofimática (deja placeholders [NOMBRE], [CARNET], [FECHA], [EMPRESA]).

ESTRUCTURA OBLIGATORIA (tamaño carta): membrete "Instituto Nueva Tecnología — Ofimática", lugar y fecha, destinatario con cargo, asunto (Asunto: Solicitud de constancia de estudios), saludo, 3 párrafos (presentación + motivo + compromiso/agradecimiento), despedida, firma con cargo, pie con contacto. Usa lenguaje formal boliviano. Configura la sección del docx a tamaño carta con márgenes 2.54 cm.

TECNOLOGÍA OBLIGATORIA: Node.js + npm + docx. Propón primero el plan: qué archivos crearás en "%USERPROFILE%\Desktop\documentos-ia\carta-constancia\" (package.json, generate.js), cómo configurarás PageSize LETTER y qué validaciones harás, sin generar aún el documento.

Revisa el plan. Si te gusta, presiona Tab para pasar a Build.

Paso 2 — Generar el .docx con Node.js + docx

En Build, pega:

Perfecto, genera ahora en "%USERPROFILE%\Desktop\documentos-ia\carta-constancia\" el proyecto Node.js:
- package.json con dependencia docx
- generate.js que use docx (Document, Packer, Paragraph, TextRun, PageSize, convertInchesToTwip) para crear Carta_Constancia_TuNombre.docx TAMAÑO CARTA (PageSize LETTER 12240x15840 twip, márgenes 1440 twip = 2.54cm) con la carta completa y placeholders visibles.
- Luego indica los comandos exactos: npm install y node generate.js
Valida que el docx abre en Word y que la configuración de página es carta.

Ejecuta lo que indique OpenCode (normalmente):

npm install
node generate.js

Abre Carta_Constancia_TuNombre.docx en Word → Diseño → Tamaño → Carta debe estar seleccionado, márgenes 2.54 cm y 7 elementos de carta (membrete, fecha, destinatario, asunto, cuerpo 3 párrafos, despedida, firma).

Variación guiada

Pide: “Cambia el motivo a solicitud de práctica pre-profesional usando el mismo script docx y regenera el .docx”. Copia el nuevo prompt con el botón y observa cómo OpenCode reutiliza Node.js/docx.

Paso 3 — Verificar tamaño carta e imprimir

  1. En Word: Diseño → Tamaño → Carta (21.59 × 27.94 cm) → Márgenes → Normal (2.54 cm) → fuente Calibri 11, interlineado 1.15, justificado, sangría primera línea 1.27 cm. Si OpenCode ya lo hizo vía docx, solo verifica.
  2. Membrete en encabezado y pie con contacto (Insertar → Encabezado).
  3. Reemplaza [NOMBRE], [FECHA] con tus datos y guarda.
  4. Archivo → Exportar → Crear PDF y comprueba en vista previa que sigue siendo carta (no A4).

Paso 4 — Verificar con OpenCode

Revisa "%USERPROFILE%\Desktop\documentos-ia\carta-constancia\Carta_Constancia_TuNombre.docx" (o el .md intermedio si existe) y dime si cumple: tamaño carta, asunto explícito, 3 párrafos, tono formal, placeholders. Sugiere 2 mejoras sin reescribir todo.

Usa /undo si algo no te convence y /share para entregar el link.

Entregable (en Escritorio\documentos-ia\carta-constancia\)
  1. generate.js + package.json (proyecto Node.js + docx).
  2. Carta_Constancia_TuNombre.docx tamaño carta y su .pdf.
  3. Link /share de Plan → Build.

Tip Desktop: mismos pasos en OpenCode Desktop → Open Project → selecciona ...\Desktop\documentos-ia\carta-constancia.
