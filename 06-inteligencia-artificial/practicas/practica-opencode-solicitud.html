Práctica 05 — Guiada

Generar una Solicitud Formal con OpenCode

Tamaño carta — carpeta Escritorio\documentos-ia — Node.js + docx

Objetivo

Emplear OpenCode en Plan → Build con Node.js + npm + docx para crear una solicitud tamaño carta (permiso / ampliación) en Escritorio\documentos-ia\ y maquetarla con membrete institucional.

Ubicación obligatoria 
mkdir "%USERPROFILE%\Desktop\documentos-ia"
mkdir "%USERPROFILE%\Desktop\documentos-ia\solicitud-ampliacion"

Trabaja siempre en C:\Users\TuUsuario\Desktop\documentos-ia\solicitud-ampliacion\.

Escenario

Solicitas al Director Académico ampliación de plazo (o permiso 2 días). Documento breve (¾ página), tamaño carta, formal, listo para imprimir con membrete.

Paso 1 — Plan con OpenCode (Tab)

cd "%USERPROFILE%\Desktop\documentos-ia\solicitud-ampliacion"
opencode

Entra a Plan (Tab) y copia:

Actúa como redactor administrativo del Instituto Nueva Tecnología. Redacta una SOLICITUD formal en español, TAMAÑO CARTA (Letter 21.59 x 27.94 cm), máximo 250 palabras, tono formal y directo, usando Node.js y npm con la dependencia docx (npm install docx).

Datos variables (deja placeholders): [NOMBRE COMPLETO], [CURSO/PARALELO], [FECHA], [DESTINATARIO: Director Académico], [MOTIVO: ampliación de plazo de entrega del proyecto de Access por motivos de salud], [FECHA PROPUESTA: 15/03/2026], [TEL/CORREO].

Estructura tamaño carta: membrete "Instituto Nueva Tecnología — Ofimática", lugar y fecha, destinatario con cargo, asunto (Asunto: Solicitud de ampliación de plazo), referencia opcional, saludo, 2 párrafos (exposición + petición con compromiso), agradecimiento, despedida, firma con nombre/curso/carnet, CC: Tutor. Configura PageSize LETTER con márgenes 2.54 cm vía docx. No inventes datos, usa placeholders.

Primero propón el plan: qué archivos crearás en "%USERPROFILE%\Desktop\documentos-ia\solicitud-ampliacion\" (package.json, generate.js), cómo configurarás tamaño carta y qué validarás, sin crear aún el archivo.

Paso 2 — Generar y refinar

Pasa a Build (Tab) y pega:

Genera en "%USERPROFILE%\Desktop\documentos-ia\solicitud-ampliacion\" el proyecto Node.js:
- package.json con dependencia docx
- generate.js que use docx para crear Solicitud_Ampliacion_TuNombre.docx TAMAÑO CARTA (PageSize LETTER, márgenes 2.54cm = 1440 twip) con la solicitud completa y placeholders.
Indica comandos: npm install y node generate.js. Valida que el docx es carta y abre en Word.
npm install
node generate.js

Itera con prompts cortos (cópialos):

Hazla 20% más breve y usa viñetas para el compromiso
Cambia el motivo a "permiso por 2 días por trámite familiar" manteniendo tamaño carta y docx
Añade al pie "Adjunto: certificado médico (opcional)" y regenera el docx

Usa /undo si empeora. Cada iteración debe seguir usando Node.js + docx tamaño carta.

Paso 3 — Maquetar en Word (verificación carta)

  1. Abre Solicitud_Ampliacion_TuNombre.docx → Diseño → Tamaño → Carta (debe ya estar) → Márgenes 2 cm, justificado 11 pt, título “SOLICITUD” centrado 14 pt negrita, asunto en negrita.
  2. Tabla 2×2 opcional para placeholders: | Estudiante | [NOMBRE] | | Curso | [CURSO] |.
  3. Reemplaza un juego de placeholders con tus datos, deja otro como plantilla.
  4. Exporta a PDF y verifica que el PDF sigue siendo carta (propiedades del documento).
Autoevaluación con OpenCode 
Evalúa "%USERPROFILE%\Desktop\documentos-ia\solicitud-ampliacion\Solicitud_Ampliacion_TuNombre.docx" con checklist: 1) Tamaño carta, 2) Asunto explícito, 3) Destinatario con cargo, 4) Motivo 1 párrafo, 5) Petición con fecha, 6) Tono formal, 7) Firma + CC, 8) Generado con Node.js+docx. Marca ✅/❌ y da 2 mejoras puntuales.
Entregable (Escritorio\documentos-ia\solicitud-ampliacion\)
  1. generate.js + package.json (Node.js + docx).
  2. Solicitud_Ampliacion_TuNombre.docx tamaño carta y .pdf.
  3. Link /share de Plan → Build → iteraciones.

Extensión

Pide: “Reusa la carta de la Práctica 08 y transfórmala en esta solicitud manteniendo placeholders, tamaño carta y docx” — compara qué conserva OpenCode.
