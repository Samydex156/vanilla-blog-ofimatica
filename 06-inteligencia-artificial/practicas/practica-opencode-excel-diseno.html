Práctica 07 — Guiada

Planilla con Diseño y Estilo Profesional en Excel con OpenCode

Tamaño carta — Escritorio\documentos-ia — Node.js + npm + exceljs con formato

Objetivo

Usar OpenCode + Node.js + exceljs para generar una planilla de control de notas/ventas con diseño profesional (colores institucionales, bordes, filtros, fórmulas y formato condicional) lista para imprimir en tamaño carta.

Ubicación obligatoria 
mkdir "%USERPROFILE%\Desktop\documentos-ia"
mkdir "%USERPROFILE%\Desktop\documentos-ia\excel-diseno"

C:\Users\TuUsuario\Desktop\documentos-ia\excel-diseno\

Pre-requisitos

  • Node.js + OpenCode (Guía) y Excel.
  • Repaso Formato de celdas y Planilla de Notas.

Paso 1 — Plan con OpenCode (Tab)

cd "%USERPROFILE%\Desktop\documentos-ia\excel-diseno"
opencode

Tab → Plan y copia:

Actúa como diseñador de planillas del Instituto Nueva Tecnología.

TAREA: Genera una planilla Excel con diseño profesional usando Node.js y npm con la dependencia exceljs (npm install exceljs), tamaño de impresión CARTA.

CONTENIDO: Hoja "NOTAS" con 15 estudiantes, columnas: Nro, Apellidos y Nombres, Nota1 (0-100), Nota2 (0-100), Nota3 (0-100), Promedio (fórmula =AVERAGE(C2:E2)), Estado (fórmula =IF(F2>=61,"Aprobado","Reprobado")). Datos realistas.

DISEÑO OBLIGATORIO (usa exceljs):
- Título en A1:G1 combinado, "Planilla de Notas — Ofimática 2026", Calibri 14 negrita, color fondo #5B3A70 (color IA), font blanco, centrado.
- Encabezados A2:G2 con fondo #D9D7CE, negrita, bordes finos, filtros automáticos y fila congelada.
- Bordes finos en todo el rango de datos, cebra suave (fila par #F7F6F3), alineación centrada en notas/promedio.
- Formato condicional en Promedio: verde si >=61, rojo si <61 (usa exceljs conditional formatting o fill según valor).
- Ancho de columnas optimizado y altura de fila 18.
- Configuración de impresión: tamaño CARTA (Letter), márgenes 0.7", orientación vertical, encabezado/pie con "Instituto Nueva Tecnología" y numeración, ajustar a 1 página ancho.

TECNOLOGÍA: Node.js + npm + exceljs. Propón el plan: archivos en "%USERPROFILE%\Desktop\documentos-ia\excel-diseno\" (package.json, generate.js), cómo aplicarás estilos, fórmulas y validaciones, sin generar aún.

Revisa plan → Tab a Build.

Paso 2 — Generar el .xlsx con estilo

Genera en "%USERPROFILE%\Desktop\documentos-ia\excel-diseno\":
- package.json con exceljs
- generate.js que cree Planilla_Notas_Diseno_TuNombre.xlsx TAMAÑO CARTA con la hoja NOTAS, fórmulas, estilos, filtros, bordes y formato condicional descrito. Usa exceljs: workbook, worksheet, font, fill, border, alignment, numFmt.
Indica comandos: npm install y node generate.js. Valida que fórmulas calculan y que la impresión es carta.
npm install
node generate.js

Abre el .xlsx en Excel: verifica que Promedio calcula, Estado cambia, y el diseño se ve como en la guía.

Paso 3 — Verificar tamaño carta y retoques finales

  1. Diseño de página → Tamaño → Carta → Márgenes 0.7″ → Orientación Vertical → Ajustar a 1 página ancho × 1 alto.
  2. Imprimir (Ctrl+P) debe mostrar título, encabezados y 15 filas sin corte.
  3. Si el docente pide, añade una segunda hoja “RESUMEN” con =PROMEDIO(F3:F17) y =CONTAR.SI(G3:G17,"Aprobado") usando el mismo script exceljs.
Check con OpenCode 
Revisa "%USERPROFILE%\Desktop\documentos-ia\excel-diseno\Planilla_Notas_Diseno_TuNombre.xlsx" y valida: 1) Tamaño carta, 2) Título combinado con color #5B3A70, 3) Filtros y bordes, 4) Fórmulas Promedio/Estado, 5) Formato condicional, 6) Generado con Node.js+exceljs. Dame 2 mejoras de estilo.
Entregable (Escritorio\documentos-ia\excel-diseno\)
  1. generate.js + package.json (exceljs).
  2. Planilla_Notas_Diseno_TuNombre.xlsx tamaño carta + .pdf.
  3. Link /share de la sesión.

Extensión
