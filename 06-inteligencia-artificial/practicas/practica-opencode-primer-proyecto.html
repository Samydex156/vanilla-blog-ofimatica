Práctica 07 — Windows

Mi Primer Proyecto con OpenCode en Windows

CLI y Desktop: explica, planifica, migra y documenta sin salir de la terminal

Objetivo

Usar OpenCode (CLI o Desktop) para explicar el proyecto vanilla-blog-ofimatica, generar un plan de migración Excel→Access y ejecutar un cambio real con control de deshacer y compartir.

Pre-requisitos

  • OpenCode CLI o Desktop instalado según Guía de instalación Windows.
  • Carpeta vanilla-blog-ofimatica clonada y abierta en PowerShell o Desktop.
  • Proveedor conectado (/connect → Zen u otro).

Parte A — CLI (PowerShell)

1. Iniciar OpenCode y crear AGENTS.md

cd C:\dev\vanilla\vanilla-blog-ofimatica
opencode
/init

Revisa AGENTS.md generado y haz git add AGENTS.md si el docente lo pide.

2. Preguntar con contexto (@)

Prueba estas 3 prompts tal cual:

Explica cómo funciona el buscador en @busqueda.js y qué IDs soporta

Resume la estructura de @07-Access/practicas/archivos/bdTienda-v1.xlsx y qué relaciones debo crear en Access

Qué hace el modo Plan (Tab) y cuándo debería usar /undo

3. Planificar antes de construir

Presiona Tab para entrar a Plan y escribe:

Quiero migrar bdTienda-v1.xlsx a Access: importa las 4 hojas, define PK, crea relaciones con integridad referencial y deja el .accdb listo para formulario. Propón pasos y qué validar en cada uno.

Itera: “Incluye cómo verificar que OpenGL no es necesario aquí” o “Añade cómo lo haría en una PC con 4GB RAM”. Cuando el plan te convenza, presiona Tab de nuevo para Build y escribe Adelante, genera el script de validación.

4. Ejecutar un cambio pequeño y deshacer

Crea un archivo 06-inteligencia-artificial/practicas/notas-opencode.md con un resumen de lo aprendido hoy (5 viñetas)

Luego prueba /undo para revertir, edita el prompt y repite. Finaliza con /share y copia el link para entregar.

Parte B — Desktop (alternativa visual)

  1. Abre OpenCode Desktop → Open Project → selecciona vanilla-blog-ofimatica.
  2. Abre una terminal integrada → verifica opencode --version (usa el mismo binario).
  3. Repite los prompts de la Parte A pero desde la GUI: verás varias sesiones en paneles, útil si el docente quiere mostrar CLI y Desktop lado a lado.
  4. Usa el botón Share de la Desktop para exportar la conversación.
Entregable
  1. Captura de opencode --version en PowerShell o Desktop.
  2. Link /share de la conversación donde OpenCode explica busqueda.js y propone el plan de migración.
  3. Archivo 06-inteligencia-artificial/practicas/notas-opencode.md creado por el agente (o captura del /undo).
Criterio de evaluación

No se evalúa código perfecto, sino proceso: preguntar con @, pedir plan antes de build, usar Tab, y saber deshacer/compartir. En PCs de 4GB, se valora usar CLI nativo y cerrar apps antes de iniciar OpenCode.
