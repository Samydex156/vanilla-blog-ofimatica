OpenCode: Tu Agente de Código con IA en la Terminal y Escritorio

Qué es, por qué usarlo en ofimática y diferencia CLI vs Desktop en Windows

Resumen

OpenCode (opencode.ai) es un agente de programación open-source creado por el equipo de SST / AnomalyCo. No es un chatbot genérico: vive dentro de tu proyecto, lee tus archivos, propone planes, escribe código, ejecuta comandos y aprende con AGENTS.md. Está disponible como TUI en la terminal (CLI), app de escritorio y extensión para VS Code.

En ofimática te sirve para automatizar tareas que antes eran manuales: generar plantillas de Word/Excel, crear scripts para migrar bdTienda/bdFarmacia a Access, documentar procedimientos y validar entregas — todo conversando en español, como si le hablaras a un colega junior.

Idea clave

Con OpenCode no copias-pegas respuestas: le pides que actúe dentro de tu carpeta (opencode), revisa el código real y te propone cambios que puedes aceptar, deshacer (/undo) o compartir (/share).

1. ¿Qué puede hacer por ti?

  • Explicar código: ¿Cómo se calcula el promedio en @03-excel/practicas/... usando @ para referenciar archivos.
  • Planificar antes de codificar: modo Plan (tecla Tab) — propone cómo implementará sin tocar archivos hasta que apruebes.
  • Automatizar ofimática: “Genera un .docx con carta modelo usando la estructura de 01-word/practicas/...” o “Crea un script Node que convierta bdTienda-v1.xlsx en tablas Access”.
  • Trabajo seguro: /undo y /redo reversibles, permisos configurables, sin exponer contraseñas.

Recomendación para el instituto (i3, 4GB, integrada)

Empieza por CLI nativo (PowerShell + npm). Es el camino de menor fricción y mejor rendimiento en 4GB. WSL2 solo si tu proyecto depende de toolchains Linux (no es el caso de vanilla-blog-ofimatica). Desktop lo dejas como segunda fase para equipos con más RAM o para el docente que gestiona varios grupos a la vez.

4. Qué necesitas antes de instalar (Windows)

  • Sistema: Windows 10 (1809+) o Windows 11 64-bit.
  • Terminal: PowerShell o Windows Terminal (ya vienen en Windows).
  • Node.js LTS (incluye npm) — se verifica con node --version y npm --version.
  • Proveedor LLM: cuenta/API key de Anthropic, OpenAI, Google o modelo local. OpenCode es agnóstico; con /connect eliges uno. Tip del curso: OpenCode Zen (opencode.ai/zen) trae modelos curados para empezar.
  • Internet: para login inicial y descargar modelos.
